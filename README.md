# Python Learning Journey 🚀

Welcome to my Python practice repository! This repo tracks my progressive learning journey in Python programming, ranging from foundational beginner CLI applications to Object-Oriented Programming (OOP), Data Structures & Algorithms (DSA), and standalone security & utility mini-projects.

## 📁 Repository Structure

```text
.
├── 01_beginner_projects/                # 14 Beginner Python Projects
├── 02_oops_practice/                    # Object-Oriented Programming Implementations
├── 03_dsa/                              # Data Structures & Sorting Algorithms
│   ├── data_structures/
│   └── sorting_algorithms/
└── 04_mini_projects/                    # Standalone CLI & Utility Projects
```

## 🎯 Modules & Content Index

### 🟢 `01_beginner_projects/`
*14 fundamental Python scripts exploring basic control flow, math, functions, and CLI user input handling.*
- `1000_celsius_to_fahrenheit_cli.py` – Temperature converter tool.
- `1001_simple_calculator.py` – Command-line basic arithmetic calculator.
- `1002_guess_the_number_game.py` – Interactive number guessing game.
- `1003_word_counter.py` – Text analyzer for counting words and characters.
- `1004_quiz_game.py` – Multiple choice question quiz program.
- `1005_countdown_cli.py` – Timer countdown CLI utility.
- `1007_contact_book.py` – Simple contact management CLI application.
- `1008_password_gen_v2.py` – Random password generator (Basic version).
- `1009_dice_roller.py` – Random dice simulation tool.
- `1010_coin_flipper.py` – Random coin toss generator.
- `1011_atm.py` – Bank account balance & transaction simulator.
- `1012_hangman.py` – Classic word guessing Hangman game.
- `1013_num_to_text.py` – Integer to text description converter.
- `1014_simple_alarm_clock.py` – Basic timer alarm script.

### 🔵 `02_oops_practice/`
*Exploring Object-Oriented Programming (OOP) concepts such as classes, objects, encapsulation, and methods.*
- `caesar_cipher_oop.py` – Object-Oriented refactor of Caesar Cipher text encryption.
- `password_generator_oop.py` – Object-Oriented class-based password generator.

### 🟣 `03_dsa/`
*Data Structures and Classical Sorting Algorithms implemented in pure Python.*
- **`data_structures/`**:
  - `linked_list.py` – Singly Linked List implementation.
  - `stack.py` – LIFO Stack structure.
  - `queue.py` – FIFO Queue structure.
  - `priority_queue.py` – Priority Queue implementation.
  - `reverse_queue.py` – Queue reversal using auxiliary structures.
- **`sorting_algorithms/`**:
  - `bubble_sort.py` – Bubble Sort algorithm.
  - `insertion_sort.py` – Insertion Sort algorithm.
  - `selection_sort.py` – Selection Sort algorithm.
  - `merge_sort.py` – Divide-and-conquer Merge Sort algorithm.
  - `quick_sort.py` – Partitioning Quick Sort algorithm.

### 🟡 `04_mini_projects/`
*Practical Python applications involving security, file operations, socket networking, and text processing.*
- `project_01_caesar_cipher.py` – Interactive CLI Caesar Cipher encoder/decoder.
- `project_02_password_generator.py` – Custom criteria password generator.
- `project_03_socket_scanner.py` – Port scanning script using Python `socket` module.
- `project_04_log_file_analyzer/` – Server log file parsing tool with `server.log` dataset.
- `project_05_password_manager.py` – Local credential management utility.
- `project_06_max_word_frequency.py` – File reader computing maximum word frequencies.

## 🛠️ How to Run
Run any script using `python3`:

```bash
# Example: Run a beginner project
python3 01_beginner_projects/1001_simple_calculator.py

# Example: Run a DSA sorting algorithm
python3 03_dsa/sorting_algorithms/merge_sort.py

# Example: Run a mini project
python3 04_mini_projects/project_01_caesar_cipher.py
```
